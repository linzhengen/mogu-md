## Detailed Description

### English

**Copy as Markdown for AI** is a lightweight Chrome extension that converts any selected HTML content — especially tables — into clean, AI-optimized Markdown. Just select, right-click, and paste into ChatGPT, Claude, or any editor.

**Why this extension?**
AI agents (ChatGPT, Claude, etc.) understand Markdown-formatted tables far better than raw HTML or plain text. When you paste a clean GFM table, the AI can immediately grasp the structure and relationships in your data.

**Features:**
- **One-click conversion:** Select content → right-click → "Copy as Markdown for AI" → paste anywhere
- **Table-aware:** Automatically expands merged cells (rowspan/colspan) into clean GFM tables
- **Noise-free output:** Removes scripts, styles, hidden elements, buttons, and other UI clutter
- **Absolute URLs:** Converts relative links to absolute URLs so AI can follow references
- **Metadata header:** Auto-prepends source URL, page title, and timestamp
- **100% local:** No data leaves your browser. No accounts, no tracking.

**Perfect for:**
- Sharing web table data with AI assistants
- Extracting structured information from web pages
- Converting documentation into LLM-friendly context
- Researchers, developers, and anyone who works with AI tools

**How to use:**
1. Select any content on a web page
2. Right-click → "Copy as Markdown for AI"
3. Paste into ChatGPT, Claude, or your editor

### 日本語

**「Copy as Markdown for AI」** は、ウェブページ上の選択範囲（特にテーブル構造）を AI エージェントが理解しやすい Markdown に変換し、クリップボードにコピーする軽量 Chrome 拡張機能です。

**特徴:**
- **ワンクリック変換:** 範囲選択 → 右クリック → 「Copy as Markdown for AI」→ そのまま貼り付け
- **テーブル対応:** rowspan/colspan の結合セルを自動展開し、GFM準拠の綺麗なテーブルに整形
- **ノイズ除去:** script/styleタグ、非表示要素、ボタンなどのUIノイズを自動除去
- **絶対URL化:** 相対パスを絶対URLに変換。AIが参照先を辿れます
- **メタデータ付与:** 取得元URL、ページタイトル、日時をMarkdownの先頭に自動挿入
- **完全ローカル処理:** データは一切外部に送信されません。アカウント登録不要、トラッキングなし

**こんな方に:**
- Webページの表データをAIに渡したい
- 構造化された情報を素早く抽出したい
- ドキュメントをLLM用のコンテキストに変換したい

**使い方:**
1. ページ上の変換したい範囲を選択
2. 右クリック → 「Copy as Markdown for AI」
3. ChatGPTやClaude、エディタに貼り付け
